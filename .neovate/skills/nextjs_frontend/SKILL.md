# Next.js 前端开发技能

## 适用范围

此技能集适用于基于 Next.js 16+ 的前端项目。

## 何时使用

当项目使用以下技术栈时参考此技能集：
- Next.js 16+ (App Router)
- React 19+
- TypeScript
- Tailwind CSS

- Framework: Next.js 16+
- UI: React 19+
- Language: TypeScript
- Styling: Tailwind CSS
- State: React Hooks + Context/Zustand
