## [0.1.0] - TBD

### 计划功能

#### 新增
- 首页工具展示页面
  - Hero 区域展示产品价值主张
  - 工具卡片网格布局
  - 响应式设计
  - SEO 优化 (metadata、结构化数据)

- 图片压缩工具
  - 支持 JPG/PNG/WEBP 格式
  - 质量滑块控制 (1-100)
  - 压缩前后对比预览
  - 一键下载功能

- 图片格式转换工具
  - JPG/PNG/WEBP 互转
  - 可选质量参数
  - 转换后下载

- 基础用户体验
  - 拖拽/点击上传
  - 实时预览
  - 处理进度指示
  - 错误提示

#### 技术实现
- 集成 sharp-wasm 图片处理库
- 使用 Zustand 状态管理
- Web Worker 多线程处理
- Next.js App Router 架构
- TypeScript 类型安全
- Tailwind CSS 样式

#### 性能优化
- WASM 文件代码分割和预加载
- 图片智能缩放预览
- 响应式图片加载
- 组件懒加载

#### SEO 优化
- 服务端渲染 (SSR)
- 结构化数据 (JSON-LD)
- 优化的 metadata
- 移动端友好设计

### 计划改进

- 错误处理完善
