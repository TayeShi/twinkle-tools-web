# VERSION-SPEC-v0.1

## 状态
in_progress

## 目标

实现核心图片处理工具，验证纯浏览器端处理的产品概念。专注于隐私保护、快速响应和简单的用户体验，作为产品MVP进行市场验证。

## 功能清单

### 必需功能 (P0)
- [ ] 首页工具展示
  - Hero 区域展示产品价值主张
  - 工具卡片网格布局 (压缩、转换工具)
  - 响应式设计 (移动/平板/桌面)
  - SEO 优化 (metadata、结构化数据)

- [ ] 图片压缩工具
  - 支持 JPG/PNG/WEBP 格式
  - 质量滑块控制 (1-100)
  - 压缩前后对比预览
  - 一键下载功能

- [ ] 图片格式转换工具
  - JPG/PNG/WEBP 互转
  - 可选质量参数
  - 转换后下载

- [ ] 基础用户体验
  - 拖拽/点击上传
  - 实时预览
  - 处理进度指示
  - 错误提示
  - 响应式设计

## 改动范围

### 新增模块
- **app/tools/image/compress/** - 压缩工具页面
- **app/tools/image/convert/** - 转换工具页面
- **app/** - 首页
- **components/** - 共享组件 (FileUploader、ImagePreview、ToolLayout)
- **stores/imageToolStore.ts** - Zustand 状态管理
- **workers/imageWorker.ts** - WASM Worker
- **types/errors.ts** - 错误类型定义

## 验收标准

### 功能验收
- [ ] 首页能正常展示工具卡片并跳转
- [ ] 压缩工具支持 50MB 以内图片，压缩率 50-80%
- [ ] 转换工具支持 JPG/PNG/WEBP 互转
- [ ] 所有操作在 30 秒内完成
- [ ] 压缩/转换成功率 > 95%

### 性能验收
- [ ] 首页 LCP < 2.5s
- [ ] 工具页面首屏加载 < 3s
- [ ] WASM 加载成功率 > 98%
- [ ] 支持低端设备 (2GB 内存)

### SEO 验收
- [ ] 首页和工具页面有优化的 metadata
- [ ] 包含结构化数据 (JSON-LD)

## 风险与依赖

### 技术风险
- **风险**: WASM 兼容性问题
  - **应对**: 优雅降级，提示用户使用支持的浏览器
- **风险**: 大图片处理失败
  - **应对**: 设置 50MB 限制，提供清晰错误提示

### 产品风险
- **风险**: 用户不相信浏览器端处理
  - **应对**: 突出隐私保护优势，展示技术原理
- **风险**: 功能过于简单
  - **应对**: 快速迭代，根据反馈添加功能

### 依赖项
- sharp-wasm 库稳定可用
- Vercel 部署正常
- Next.js 16+ App Router
