# 项目上下文

## 当前版本

**v0.1 MVP** (进行中)

核心目标: 实现图片压缩和格式转换工具，验证纯浏览器端处理的产品概念。

开始时间: 2026-01-15
预计完成: 2026-02-01

## 产品定位

**核心价值主张**: 一款完全在浏览器中运行的在线图片处理工具，不上传任何数据到服务器，保护用户隐私，提供快速、安全的图片处理体验。

**目标用户**:
- 需要快速处理图片的普通用户
- 关注隐私和安全的专业人士
- 需要批量处理图片的内容创作者
- 不想安装桌面软件的临时使用者

## 技术架构

### 核心技术栈
- **框架**: Next.js 16+ (App Router)
- **语言**: TypeScript
- **样式**: Tailwind CSS
- **状态管理**: Zustand
- **图片处理**: sharp-wasm (WebAssembly)
- **部署**: Vercel

### 架构原则
- **纯客户端处理**: 所有图片处理在浏览器完成，零服务端依赖
- **SSR + 客户端组件**: 服务端组件用于 SEO，客户端组件处理交互
- **Worker 多线程**: WASM 处理在 Worker 中进行，避免阻塞主线程
- **静态生成**: 工具页面使用 SSG，无需数据库

### 当前模块 (v0.1)

- imageToolStore: 图片工具状态

**Worker**
- imageWorker: WASM 图片处理

## 已知约束

### 技术约束
- **WASM**: 所有图片处理依赖 sharp-wasm
- **浏览器支持**: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **文件大小**: 最大支持 50MB 图片
- **处理时间**: 单张图片处理不超过 30 秒

### 性能约束
- **首页 LCP**: < 2.5s
- **工具页面加载**: < 3s
- **低端设备**: 支持 2GB 内存设备

### 隐私约束
- **数据处理**: 100% 客户端处理
- **数据传输**: 不向任何服务器发送用户数据
- **数据存储**: 不收集用户个人信息

### SEO 约束
- **架构**: 使用 SSR 生成 SEO 友好的 HTML
- **结构化数据**: 包含 JSON-LD
- **移动端**: 响应式设计，移动端友好
